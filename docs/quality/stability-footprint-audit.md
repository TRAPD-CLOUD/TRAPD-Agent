# Endpoint stability and footprint audit

Baseline `9e00c89`. Locations refer to that revision. The review covers Linux and Windows userspace in `agent/` and `crates/`. The `trapd-agent-ebpf/` crate contains kernel code. Its userspace readers live under the Linux collectors.

The release budget is below 1% idle CPU and 150 MB steady-state RSS. The byte ceilings below apply to specific allocations or serialized payloads. Their sum does not establish the working set of a running endpoint.

Collector paths beginning with `linux/`, `windows/` or `logs/` are relative to `agent/src/collectors/`. Other abbreviated agent paths are relative to `agent/src/`.
